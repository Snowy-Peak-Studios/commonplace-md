# Pocket Garden

A three-person team building a window garden planner. Start with the [[Task Board]] to see what can be tried this week. The [[Team Inbox]] links to each person's inbox.

| Person | Area | Focus |
| --- | --- | --- |
| Tavi Vale | Product | Decide how reminders should work |
| Neri Holt | Design | Make the garden list easy to scan |
| Miro Finch | Engineering | Save care notes and reminders |

Open [[Design the garden list]] to see how one person owns a task and another reviews it.

Drafts and work in progress that only you need go in a `_local_only/` folder. This vault's `.gitignore` keeps it out of the repo, so it stays on your device: don't link to its notes from shared ones. Move a note out when it's ready to share.
