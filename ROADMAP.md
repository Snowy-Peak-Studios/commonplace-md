# 🗺️ Roadmap

What we're working on for Commonplace.md, and what comes next. It changes as the work moves. Got an idea or found a bug? [Open an issue](https://github.com/Snowy-Peak-Studios/commonplace-md/issues).

The same list is a task board in [`roadmap/`](roadmap/Roadmap.md): one note per task and a board over them, the way Commonplace.md keeps tasks. Open the repo in Commonplace.md with the folder `roadmap` to see it there.

## 🔨 Working on now

- **Agile tasks**: types, subtasks, sprints, estimates and your own fields, set up per project.
- **Images in notes**: paste, drop or pick an image, and it's saved in your repo and linked into the note.
- **Modules**: turn the parts of the app you need on and off, down to a bare wiki.
- **Share notes without a GitHub account**: let someone read a page or a whole vault without signing in.

## 🔭 Exploring

- **A more agile task board**: updating the task board to be more agile-based.

## ✅ Recently done

- **A roadmap you can see**: this page, kept up to date as the work moves.
- **Install it as an app**: the README shows how to install Commonplace.md on a computer or a phone.
- **Rules and prompts for AI agents**: the example vault comes with rules for agents, and the README has prompts to copy: one that sets everything up, one that starts a working session.
- **Reload beside Save, and a heads-up when notes change**: a Reload button next to Save, and a quiet note when the notes on GitHub are newer than the ones you have open.
