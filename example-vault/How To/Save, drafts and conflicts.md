# Save, drafts and conflicts

> [!TIP]
> **tl;dr:** **Save** is one commit. Unsaved changes stay on the device as a draft. If someone saved the same note first, you see both versions and pick: nothing is lost.

## Save

Press **Save** (or Ctrl+S). Each save is one commit in your repo. A note with unsaved changes has a dot in its title.

Ticking a checkbox in Read mode is a change too: **Save** keeps it.

## Drafts

What you type is kept on the device until it's saved. If you close the note (or the app) first, the next time it opens it offers the changes back: **Restore them** or **Discard**.

Moving away from a note with unsaved changes asks first: **Save**, **Keep as a draft**, **Discard** or **Stay**.

**Settings › This device** shows how many drafts are kept, and can discard them all.

## Conflicts

If someone saved the same note on GitHub after you opened it, GitHub refuses your save. The app then shows both versions side by side: theirs, and yours (which you can still change). Pick:

- **Save my version**: yours replaces theirs.
- **Use the GitHub version**: theirs stays, and your changes go.
- **Decide later**: nothing changes yet; your changes stay as a draft.

Nothing is lost until you pick.

## Newer notes on GitHub

When someone saves from another device, a quiet banner says there are newer notes. Press its **Reload** to read them.
